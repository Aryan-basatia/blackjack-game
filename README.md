# Blackjack Game

## Project Overview
This Blackjack Game is a simple implementation of the classic card game where players try to reach a hand value of 21 without going over. It can be played against a dealer with standard blackjack rules and offers an engaging experience for both new and experienced players.

## Features
- Play against a computer dealer
- Hit or stand options
- Clear display of current hand and dealer's hand
- Option to play multiple rounds
- Reset game feature

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Aryan-basatia/blackjack-game.git
   ```
2. Navigate into the project directory:
   ```bash
   cd blackjack-game
   ```
3. Open the `index.html` file in your web browser.

## Usage
To start playing the game, simply refresh the browser window and follow the on-screen instructions to hit or stand. The game will display your hand value against the dealer's hand.

## Gameplay
- The game begins with you and the dealer being dealt two cards.
- You can choose to hit (take another card) or stand (keep your current hand).
- The aim is to get as close to 21 as possible without exceeding it.
- The dealer must stand on 17 and must hit on 16 or lower.
